UniFi Protect Camera / Doorbell

UniFi Protect for Control4 · version 1.0.1 · Open Source (MIT). Not affiliated with Ubiquiti Inc. or Snap One LLC.

Setup

  1. Add the driver to the room where the camera should appear (Navigator Cameras).
  2. Pick the camera or doorbell in Protect Device. Connection Status turns to Connected.
  3. Optional: bind the Doorbell Button, Motion or Smart Detection contact outputs to stock contact drivers (for example the Control4 Doorbell contact driver) if you want their icons and history.

Live video

Navigators receive High, Medium and Low RTSP streams and pick the right one by tile size (Preferred Stream = Auto). A controller-served MJPEG stream is offered as a fallback. Set Stream Codec to H.265 only when the camera uses Enhanced Encoding in Protect.

Event history and recorded playback

Requires Local Username/Local Password on the master. Open the camera in Navigator, then the Extras tab:

  • Play Recent Event – the latest rings, motion and smart detections (window and count set by History Hours, History Events, History Filter). Picking one switches the camera view to the recording, starting Playback Pre-Roll seconds before the event.
  • Play From – jump back 30 seconds to 24 hours.
  • Playback Speed – 1x, 2x, 4x or 8x.
  • Back to Live – return to the live stream. Playback also returns to live after Playback Timeout.

Playback is delivered as MJPEG built from frames on the Protect timeline, so it runs at a low frame rate (Playback FPS) without audio. It is meant for checking what happened, not as a replacement for the Protect app's full player. Re-open the camera view if a Navigator keeps showing the previous stream.

Doorbells and announcements

Doorbells are detected automatically (or set Doorbell Mode). On every ring the driver:

  • fires the Doorbell Pressed event (repeat presses inside Ring Cooldown are ignored so announcements do not stack up),
  • sets RINGING true for Ringing Hold seconds and updates LAST_RING, RING_COUNT and LAST_EVENT_THUMBNAIL_URL,
  • pulses the Doorbell Button contact output.

Announcement example: Programming › select this camera › When Doorbell Pressed › drag your Announcement (Agents › Announcements, e.g. "Someone is at the front door") into the script. Add a camera pop-up or push notification in the same script if you like.

Doorbell display messages: Extras › Doorbell Display Message (presets plus Doorbell Custom Messages), or the programming commands Set Doorbell Message, Doorbell Message Preset, Clear Doorbell Message.

Child drivers find the master automatically when there is exactly one master in the project. With several consoles, bind each child's UniFi Protect connection to the right master. Then pick the device in the child's Protect Device property.

Troubleshooting

  • Child says Waiting for UniFi Protect master driver: add the master, or bind the child's UniFi Protect connection when there is more than one master.
  • No video but snapshots work: make sure Navigators can reach the console on TCP 7447 (RTSP) and try Preferred Stream = Low.
  • Run the master's Print Devices to Lua Output action and set Debug Logging = On to see the traffic in the Lua tab.
