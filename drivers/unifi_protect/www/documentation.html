The driver set

UniFi Protect (unifi_protect.c4z)Master. Connects to the console, keeps the realtime event streams open and serves all children. Add one per Protect console.

Child drivers find the master automatically when there is exactly one master in the project. With several consoles, bind each child's UniFi Protect connection to the right master. Then pick the device in the child's Protect Device property.

Setup

  1. API key – In UniFi OS open Settings › Control Plane › Integrations and create an API key. Paste it into API Key. Requires UniFi Protect 6.0 or newer.
  2. Set Console Address to the console / NVR IP (port 443 unless changed). Connection Status shows Connected - Protect x.y.z and Realtime Events shows Connected.
  3. History and playback (optional) – Create a local UniFi OS user with view access to Protect (not a UI.com cloud account with MFA) and enter it in Local Username / Local Password. Protect only offers event history and recorded footage through this login; API keys cannot read them. Recordings Access confirms it works.
  4. Add the child drivers you need (see below).

Video and the media server

Live video goes straight from the console to Navigators over RTSP (port 7447, or RTSPS 7441). The master turns on the RTSPS streams for each camera through the Integration API automatically.

Snapshots, the MJPEG fallback stream and recorded playback come from a small media server inside the master driver (default port 8641 on the controller). Navigators never need Protect credentials. URLs carry a random access token. If the controller has more than one address, set Media Server Address to the one Navigators can reach.

Remote (off-site) Navigators can only show video if they can reach the console and controller addresses, for example over a VPN.

Programming

Events: Console Online, Console Offline, Any Doorbell Ring (variable LAST_RING_CAMERA holds the doorbell name).

Actions: Reconnect, Refresh Devices, Recreate Camera Streams, Find Child Drivers, Print Devices to Lua Output.

Troubleshooting

  • Child says Waiting for UniFi Protect master driver: add the master, or bind the child's UniFi Protect connection when there is more than one master.
  • No video but snapshots work: make sure Navigators can reach the console on TCP 7447 (RTSP) and try Preferred Stream = Low.
  • Run the master's Print Devices to Lua Output action and set Debug Logging = On to see the traffic in the Lua tab.
